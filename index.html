This document defines the operating model for Qcells software engineering teams using AI-augmented, specification-driven development. Architects specify designs, senior developers use Claude Code agent teams to implement, TPMs track delivery, and dev managers oversee people and process.

💡 The Core Idea

The specification becomes the atomic unit of planning, execution, and reporting. Every role's work revolves around writing, implementing, or tracking specs. AI handles the code generation; humans handle the judgment.

02 Spec Lifecycle

Every piece of work flows through these seven phases. The spec is the thread that connects them all.

1

Spec

Owner: Architect

Architect writes a detailed spec with API contracts, data models, system flows, and acceptance criteria.

2

Review

Owner: Architect + Sr. Developer

Spec reviewed for clarity, feasibility, and completeness. Sr. Dev validates it can be effectively translated to agent prompts.

3

Prioritize

Owner: TPM

TPM sequences the spec into the sprint/cycle based on roadmap priorities and cross-team dependencies.

4

Implement

Owner: Sr. Developer

Sr. Dev orchestrates Claude Code agent teams to build against the spec. Prompts derived from spec content.

5

Validate

Owner: Sr. Developer + Architect

Code reviewed against spec. Architecture compliance checked. Acceptance criteria verified.

6

Ship

Owner: Sr. Developer

Merged, deployed, and marked done in tracking. Spec status updated.

7

Report

Owner: TPM

Progress rolled up from specs → features → milestones for executive reporting.

Feedback Loops

Sr. Dev → Architect

Spec gaps or ambiguities discovered during implementation feed back into spec improvements.

Architect → Sr. Dev

Code review findings inform spec template and prompt library improvements.

TPM → Architect

Velocity data informs spec sizing, decomposition, and planning accuracy.

Dev Mgr → All

Process health insights drive continuous improvement across all roles.

04 The Transformation

❌ Before

Large dev teams write code manually. Architects design, hand off, and hope. Progress is tracked in story points — an opaque proxy for value. Knowledge lives in people's heads.

✅ After

Architects write precise specs. Senior devs use AI agent teams to implement at 3–5× velocity. Every spec maps to a feature. Progress is tracked in delivered, verified functionality — not effort.

Bottom Line

Smaller, senior-heavy teams. Higher throughput. Predictable delivery. Direct traceability from investment → spec → feature → business value.
